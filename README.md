# TaskApp Backend (Express + MongoDB)


A complete backend for a task-tracking and collaboration application.


## Features
- JWT authentication (register, login)
- User profile management
- Task CRUD with assignment, status, priority, due dates
- Teams/Projects and membership
- Comments and attachments (multer)
- Task filtering, searching, sorting
- Socket.IO scaffolding for real-time notifications


## Quick start (development)


1. Copy `.env.example` to `.env` and update values.
2. Install dependencies:


## bash
npm install
